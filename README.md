## 📌 About this Branch (`web`)

This branch contains the static assets deployed to **GitHub Pages**:
- **`index.html`**: Responsive landing page with interactive player simulator, feature cards, and download buttons.
- **`style.css`**: Modern dark glassmorphism design system, ambient glow animations, and responsive layouts.
- **`script.js`**: Interactive demo simulating live synchronized line-by-line scrolling lyrics and mode switching.
- **`.nojekyll`**: Bypasses Jekyll processing on GitHub Pages for instant static file serving.
