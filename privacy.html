Privacy Policy

Last updated: September 7, 2026 • Universal Desktop Lyrics

1. Summary (TL;DR)

Universal Desktop Lyrics is an open-source, non-commercial software application. We believe your listening habits, personal data, and system activity belong exclusively to you.

The Core Promise: We do not collect, track, store, or sell any personal data. There are no tracking cookies, no telemetry beacons, no user accounts, and no advertising trackers.

  • ✔ Zero Telemetry: No analytics libraries or diagnostic trackers (e.g. Sentry, Google Analytics, Firebase) are integrated.
  • ✔ No Logins Required: You never need to supply an email address, username, or password to use any feature.
  • ✔ Local-Only Audio Detection: Music detection is performed purely on your machine using native operating system media session APIs.
  • ✔ Transparent Source Code: 100% of our code is public and verifiable on GitHub under the MIT License.

2. Information Processed Locally on Your Computer

To synchronize scrolling lyrics with your music, the application interacts with your local computer's media transport system:

A. Media Playback Metadata

When you play audio in Spotify, Apple Music, YouTube, Chrome, Edge, VLC, or Firefox:

  • ✔ What is read: Track title, artist name, album name, playback status (playing/paused), and current playback position.
  • ✔ How it is read: On Windows, via the native WinRT GlobalSystemMediaTransportControlsSessionManager. On macOS, via an AppleScript/JXA bridge connecting directly to Spotify and Apple Music.
  • ✔ Storage: Processed exclusively in volatile computer memory (RAM) while playing. This data is never transmitted to any private server or third party.

B. App Preferences & Appearance

Your selected window mode (Dynamic Island, Floating Widget, Compact Bar, or Full Canvas), chosen theme, window opacity, and hotkey preferences are stored strictly in your browser's local sandbox (localStorage) on your machine.

C. Offline Lyrics Cache

When lyrics are retrieved, they are cached locally in your application storage so that repeating songs load instantaneously without re-requesting data from the network.

3. Network Communications (What Leaves Your Device)

Universal Desktop Lyrics connects to the internet strictly to retrieve public lyrics:

A. LRCLIB Public API

When a song starts or when you perform a manual search, the application sends a standard HTTPS request to LRCLIB (an open, community-driven lyrics database).

  • ✔ Data Sent: Song title, artist name, and track duration (in seconds) to match timing.
  • ✔ No User Identifiers: We do not send any user ID, account name, device serial number, or tracking cookies to LRCLIB.

B. GitHub Releases (Update Checks)

When checking for software updates, the application queries the public GitHub Releases API for the Desktop Lyrics repository to compare version numbers. No personal information is provided.

4. What We Do NOT Collect

  • ✖ No Personal Information: We do not collect names, email addresses, phone numbers, or IP logs.
  • ✖ No Keystroke Logging: Global shortcuts (like Ghost Mode toggle Ctrl+Shift+X) are registered strictly through the operating system's standard hotkey manager and evaluated only for app control.
  • ✖ No Microphone or Camera Access: The application does not require, request, or use audio recording permissions.
  • ✖ No File Access Outside App Sandboxes: The application does not scan or read your local file system or browsing history.
  • ✖ No Advertising: Universal Desktop Lyrics is ad-free and will remain ad-free forever.
